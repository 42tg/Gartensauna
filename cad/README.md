# CAD

Ziel: Parametrisches FreeCAD-Modell mit editierbarer Geometrie, STEP-Export, Grundriss und Schnitten.

## Erste Parameter (mm)
- Länge: 3200 (Bestandsmaß)
- Tiefe: 1700 (Bestand), Variante 2000 (Planungsannahme)
- Höhe Bestand: 1930 (Messpunkt noch offen)
- Höhe vorne, Konzept V1: 2300 (Planungsannahme)

**Hinweis:** Die zuvor im Chat bereitgestellten CAD-Dateien sind noch nicht in diesem Repository. Nicht so tun, als seien sie hier versioniert.
